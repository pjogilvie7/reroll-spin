# ReRoll

Spin the wheel. Watch a whole anime life get rolled. Post it to your own TikTok.

ReRoll is a desktop app that generates anime wheel-spin videos (Naruto, Jujutsu Kaisen, Chainsaw Man, Bleach, Demon Slayer, My Hero Academia, Black Clover, Solo Leveling, and a Multiverse wheel) and posts them to a TikTok account you control through TikTok's official Login Kit and Content Posting API.
